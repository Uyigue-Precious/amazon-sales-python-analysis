# Amazon Sales Exploratory Data Analysis Using Python

## Project Overview

This project analyzes an e-commerce sales dataset to understand sales performance, product category performance, regional trends, and customer purchasing behavior.

The analysis was performed using Python and Pandas, with visualizations used to identify patterns and generate business insights.

## Dataset

The dataset contains:

* 5,000 rows
* 13 columns
* No missing values
* No duplicate records

The data contains information relating to sales, products, customers, regions, dates, and order quantities.

## Analysis Performed

The analysis covered:

1. Overall sales performance
2. Monthly sales trends
3. Product category performance
4. Regional performance
5. Customer purchasing behavior
6. Relationship between sales and quantity
7. Business insights and recommendations

## Key Findings

* Total sales: **32,866,573.74**
* Total quantity sold: **149,970**
* Sales varied considerably across different months.
* Product categories generated relatively similar levels of revenue.
* Regional sales were relatively evenly distributed.
* Order quantities from 1 to 5 were also relatively balanced.

## Data Limitations

The dataset did not contain profit, cost, or sub-category variables. Therefore, profitability analysis and sub-category analysis could not be performed directly.

Identifying these limitations was an important part of the analysis because business conclusions should be based on the variables actually available in the dataset.
